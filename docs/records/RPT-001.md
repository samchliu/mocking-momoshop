# RPT-001：Agent 協作紀錄與效率分析

## 目的

記錄 Phase 1／Phase 2 中人與 agent 的分工、agent 產出被修改或否決的地方，以及協作效率，作為 ADR-004 是否有效的證據。

## 環境與方法

- 工具：Claude Code（主 agent，擔任整合者）＋ 依 ADR-004 派出的 feature agent（上限 3）。
- 每個 agent 任務的輸入：`docs/_build/features/REQ-xxx/ai-context.md` ＋ 指定檔案範圍。
- 閘門：`npm run verify`（含 `kb validate --code-root .` 與 `spec:check`）＋ 人工 review diff。
- 量測：每個任務的開始／結束 commit 時間、review 中發現的問題數、退回次數。
