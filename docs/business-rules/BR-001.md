# BR-001：價格顯示規則

> **核准後即為權威。** 程式碼、mock 資料與本文件不一致時，回報為衝突。

## 規則

| #   | 規則                                                                                                                                        |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| R1  | 金額必須是非負整數新台幣（元），顯示為 `$` 加千分位，例如 `$43,900`；非法值顯示 `—`，不得顯示 `NaN` 或小數                                  |
| R2  | 有原價（listPrice）且原價大於售價時，必須同時顯示刪除線原價與折數；否則不得顯示原價與折數                                                   |
| R3  | 折數 = 無條件捨去 (售價 ÷ 原價 × 100)。結果為 10 的倍數時顯示「N 折」（70 → 「7折」），否則顯示兩位數（95 → 「95折」）；折數 ≥ 100 時不顯示 |
| R4  | 商品頁的價格區塊只使用兩種名稱：「售價」（主）與「原價」（刪除線）；不使用實站的「售價已折／限時折後價／促銷價／市售價」                    |
| R5  | 限搶價只在限搶期間（開始 ≤ 現在 < 結束）顯示；期間外必須顯示一般售價                                                                        |
| R6  | 商品有多個規格且售價不同時，卡片顯示最低售價並加註「起」                                                                                    |

## 參數

| 參數     | 值  | 使用於 | 備註         |
| -------- | --- | ------ | ------------ |
| currency | TWD | R1     | 不支援多幣別 |

## 理由

| 規則 | 為什麼                                                                                    | 證據                 |
| ---- | ----------------------------------------------------------------------------------------- | -------------------- |
| R1   | 金額用整數運算避免浮點誤差；千分位是台灣電商慣例                                          | REF-002              |
| R2   | 原價不高於售價時顯示折扣會誤導                                                            | —                    |
| R3   | 台灣慣用「N 折」；捨去而非四捨五入，避免把 7.96 折顯示成「8折」以下的更優惠印象           | —                    |
| R4   | 實站多種價格名稱語意重疊，mock 範圍內簡化為兩種，降低使用者與維護者的理解成本（刻意差異） | REF-002 備註         |
| R5   | 過期的限搶價屬於錯誤標價                                                                  | REF-002 首頁限時搶購 |
| R6   | 與實站「$469 起」的呈現一致                                                               | REF-002              |

## 適用條件

所有顯示金額的元件：商品卡、商品頁、限時搶購。

## 例外

| 例外   | 適用於 | 核准者 |
| ------ | ------ | ------ |
| （無） |        |        |

## 範例

| #   | 情境                 | 預期結果                        | 規則   |
| --- | -------------------- | ------------------------------- | ------ |
| E1  | 售價 43900           | `$43,900`                       | R1     |
| E2  | 售價 -1 或 NaN       | `—`                             | R1     |
| E3  | 售價 700、原價 1000  | 顯示原價 `$1,000` 與「7折」     | R2, R3 |
| E4  | 售價 950、原價 1000  | 「95折」                        | R3     |
| E5  | 售價 799、原價 1000  | 「79折」（捨去，不是 80 → 8折） | R3     |
| E6  | 售價 1000、原價 1000 | 不顯示原價與折數                | R2     |
| E7  | 限搶結束時間已過     | 顯示一般售價                    | R5     |
| E8  | 規格售價 469／711    | 卡片顯示 `$469 起`              | R6     |
