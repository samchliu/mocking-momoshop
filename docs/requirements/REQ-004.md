# REQ-004：全站版面骨架

## 問題

目前的版頭只有一列（Logo、搜尋、購物車），內容寬度與底色也和實站不同，使用者一眼就覺得「不像 momo」，而且沒有不靠打字就能進入商品分類的入口。

## 目標

- 版面骨架的寬度、底色、版頭結構符合本文件「參數」所列數值，所有頁面共用。
- 提供一列可點擊的分類導覽，一鍵進入搜尋結果。

## 使用者

所有訪客（桌機與手機）。

## 用語

| 用語         | 定義                                                                                                                                                                                                                     |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 容器         | 即 `<main>` 元素：水平置中、白底，寬度 = min(1220px, 可視區寬 − 32px)。可視區寬指 `document.documentElement.clientWidth`（不含捲軸）。可視區寬 < 1252px 時，容器左右兩側各露出 16px 頁面底色（外距，不是容器的 padding） |
| 分類導覽項目 | `{ 顯示文字, 搜尋關鍵字 }`；本版兩者相同，即「參數」表所列的字串                                                                                                                                                         |
| 目前分類     | 只在 `/search/:keyword` 路由下計算：keyword 依序經 URL decode → BR-002#R1 正規化 → `toLowerCase()`，與分類導覽項目的搜尋關鍵字 `toLowerCase()` 後以 `===` 比較；相等者即為目前分類。其他路由沒有目前分類                 |

## 範圍

### 範圍內

- 容器、頁面底色、兩列版頭、分類導覽。
- 套用範圍：`Layout` 之下的所有路由，包含首頁、搜尋、商品、購物車與 404 頁。根層級錯誤畫面（路由錯誤時取代整個 `Layout` 的 `RouteErrorPage`）不含版頭，也不套用容器與頁面底色。

### 不在範圍內（Out of scope）

- 頂端工具列（登入、註冊、會員中心、查訂單…）：沒有會員與訂單功能，放了只會是死連結。
- 右側浮動欄（瀏覽紀錄、購物車、TOP）、版頭活動圖。
- 實站的完整品類樹、多層選單，以及分類連結的 hover 展開。
- 捲動時的固定與收合行為由 REQ-005 規定（版頭固定在視窗頂端；捲動後只留第一列、隱藏分類導覽）。

## 驗收條件

| #   | 條件                                                                                                                                                                                                                                                                                                                                                                                                                                             | 規則      | 驗證方式                    |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------- | --------------------------- |
| AC1 | [P0] 版頭背景為白色並橫跨整個視窗寬度，版頭內容置於容器內；主內容置於容器內且容器背景為白色；`body` 背景為頁面底色。視窗 1440px 時，主內容容器寬度為 1220px（±1px），容器左右兩側可見頁面底色；視窗 1000px 時容器寬度為 968px（±1px）                                                                                                                                                                                                            | —         | e2e（量測容器寬度與背景色） |
| AC2 | [P0] 版頭在所有寬度都是兩列（第一列不換行）。第一列依序為 Logo（`href="/"`，可及名稱「momo shop 首頁」）、搜尋框、購物車徽章。第二列為 `<nav aria-label="商品分類">`，內含依「參數」順序排列的分類連結；每個連結的 `href` 為 `/search/` 加上 `encodeURIComponent(搜尋關鍵字)`，不帶任何查詢參數（排序、篩選、頁碼回到預設）。參數表的關鍵字本身已符合 BR-002#R1，產生 `href` 時不再正規化。例：「吹風機」→ `/search/%E5%90%B9%E9%A2%A8%E6%A9%9F` | BR-002#R1 | app（元件測試）             |
| AC3 | [P1] 目前分類的連結帶 `aria-current="page"`，文字色為品牌色 `var(--color-brand)`；其他分類連結不帶 `aria-current`，文字色為 `var(--color-text)`。例：`/search/ｉｐｈｏｎｅ` 標示 iPhone；`/search/iPhone 15` 不標示任何分類；首頁與商品頁不標示任何分類                                                                                                                                                                                          | BR-002#R1 | app（元件測試）             |
| AC4 | [P1] 分類導覽在所有寬度都是單列、不換行；放不下時可水平捲動；不顯示水平捲軸（仍可用觸控、觸控板、Shift＋滾輪與 Tab 聚焦水平捲動），不加漸層、箭頭等額外提示。視窗 < 768px 時，每個分類連結的點擊區寬與高皆 ≥ 44px。以 Tab 聚焦到捲動範圍外的連結時，該連結的外框完全落在 `nav` 的可視範圍內                                                                                                                                                      | —         | e2e（desktop + mobile）     |
| AC5 | [P1] 每個分類導覽項目的搜尋關鍵字，以預設條件（不帶篩選、預設排序）在 mock 後端搜尋，結果至少 1 筆；不足時補 mock 商品，不修改分類清單                                                                                                                                                                                                                                                                                                           | BR-002#R2 | api/mock（單元測試）        |

## 參數

| 參數                       | 值                                                                     | 說明                                                                                      |
| -------------------------- | ---------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| 容器最大寬                 | 1220px                                                                 | 可視區寬 < 1252px 時，容器兩側外距各 16px                                                 |
| 頁面底色                   | `#f2f2f2`（token `--color-bg-page`）                                   |                                                                                           |
| 版頭與容器底色             | `#ffffff`（token `--color-bg`）                                        |                                                                                           |
| 品牌色                     | `#d62872`（token `--color-brand`）                                     |                                                                                           |
| 分類導覽項目（依顯示順序） | iPhone、Galaxy、Pixel、MacBook、AirPods、Dyson、吹風機、保護貼、手機殼 | 前端常數，不呼叫 API，因此沒有載入中與失敗狀態。點擊後的載入、錯誤、空結果依 REQ-001 處理 |

## 補充行為

- 版頭搜尋框的值等於目前 `/search/:keyword` 的 keyword（URL decode 後的原值）；路由改變時覆蓋搜尋框中尚未送出的輸入。其他路由搜尋框為空。
- 目前分類與其他分類只有文字色不同；字級、粗細、hover／focus 樣式相同（focus 外框沿用全站 `--color-focus`）。
- 容器不設最小高度；版頭與容器之間沒有間隔。
