# REQ-002：商品頁與加入購物車

## 問題

使用者從搜尋點進商品後，需要確認價格、選擇規格與數量，並放心地加入購物車：不會因為連點而重複加入，庫存不足時被清楚告知。

## 目標

- 價格資訊一致且不誤導（BR-001）。
- 「加入購物車」在慢速或失敗時仍維持正確狀態（BR-003）。

## 使用者

| 使用者           | 需要                                   |
| ---------------- | -------------------------------------- |
| 比較中的購物者   | 價格、規格、庫存、限購資訊一目了然     |
| 決定購買的購物者 | 加入購物車有明確回饋，版頭數量即時更新 |

## 用語

| 用語         | 定義                                                                              |
| ------------ | --------------------------------------------------------------------------------- |
| 選項（規格） | 可選的 variant（API 的 `variants`）。AC1–AC5 與 BR-003 中的「規格」皆指選項       |
| 規格表       | 商品的規格說明 `specs`（API-001），只在「商品規格」分頁呈現；有無規格表不影響 AC2 |

## 範圍

### 必須（Must）

- 圖片、品牌、品名、價格區塊、規格選擇、數量、加入購物車
- 版頭購物車數量徽章（跨頁、重新整理後保留）

### 應該（Should）

- 麵包屑（Home > 分類 > 商品）
- 舊網址相容：`/goods/GoodsDetail.jsp?i_code=<id>` 導向 `/goods/<id>`

### 可以（Could）

- 相關商品：同品牌其他商品的連結（與實站的「熱門推薦」商品帶不同，後者不在範圍內）。本次（CR-001）不實作

### 不在範圍內（Out of scope）

- 購物車頁、結帳、折價券、分期試算、配送方式、會員登入
- 左側品類側欄、活動區塊（登記送）、組合商品內容、熱門推薦
- 「直接購買」「加入追蹤」按鈕（結帳與會員不在範圍內）

## 未解問題
