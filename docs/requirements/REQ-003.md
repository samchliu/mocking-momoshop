# REQ-003：首頁

## 問題

沒有明確目標的使用者需要被引導：看到活動、限時優惠與熱門商品，並能一鍵進入搜尋。

## 目標

- 首屏快速呈現（LCP 圖片優先載入），首屏以下延遲載入。
- 限時搶購的倒數與價格正確。

## 使用者

| 使用者       | 需要                                 |
| ------------ | ------------------------------------ |
| 逛街型購物者 | 活動、限時優惠、熱門商品、熱搜關鍵字 |

## 範圍

### 必須（Must）

- 主視覺輪播
- 限時搶購（倒數、限搶價／原價、剩餘組數）
- 商品帶（大家都在買）

### 應該（Should）

- 熱搜關鍵字（點擊導向搜尋）

### 不在範圍內（Out of scope）

- 排行榜、今日大牌、個人化推薦、瀏覽紀錄、右側浮動工具、`/discover`、`/live`
