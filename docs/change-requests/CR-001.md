# CR-001：版面骨架對齊實站、商品頁主區排版與詳情分頁

## 要求的變更（Requested Change）

> 「接下來要對齊 layout，與完善商品頁」；範圍選定：全站版面骨架、商品頁主區改為實站排版、商品詳情分頁。
> —— 負責人，2026-11-20

## 原因（Reason）

2026-11-20 以瀏覽器重新檢視實站（REF-002 補充觀察，量測值見下）。目前版面與實站差異最大的是：單列版頭（實站為兩列 + 分類導覽）、內容區寬度與底色、商品頁缺少「標籤：值」資訊表與詳情分頁。

實站量測（desktop 1470px 視窗）：

| 項目       | 量測值                                                               |
| ---------- | -------------------------------------------------------------------- |
| 內容區     | 約 1220px 置中；首頁兩側底色 `#f2f2f2`                               |
| 分類導覽   | 單列、17px／600、`#404040`，目前分類為品牌色                         |
| 商品頁主區 | 左側品類欄 198px（本次不做）＋ 圖片約 440px ＋ 資訊約 528px          |
| 資訊表     | 品牌名稱、結帳方式、分期、配送方式、數量、折價券，「標籤：值」排列   |
| 按鈕       | 直接購買／放入購物車／加入追蹤，各 160×40、方角、16px／600           |
| 詳情分頁   | 商品特色／商品規格／退換貨須知／相關類別；規格為兩欄表格，標籤欄灰底 |

**風險／副作用：**

- 版頭變兩列會讓首屏內容下移約 40px；需確認 Lighthouse CLS／LCP 不退步。
- 分類導覽以「熱門關鍵字」實作（見 REQ-004#AC2），與實站的品類樹不同。

**未解問題：**

- 無。歧義檢查（2026-11-20）提出的問題已寫入 REQ-004、REQ-002（AC8–AC11、用語、參數）與 API-001（`specs` 規則）。
- 退換貨須知使用 REQ-002「參數」所列的固定文案。
- 「直接購買」「加入追蹤」不做（REQ-002 不在範圍內），按鈕列只有「放入購物車」。
