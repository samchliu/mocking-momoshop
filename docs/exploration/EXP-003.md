## 觀察證據（2026-11-20）

環境：桌機版 `cart.momoshop.com.tw/view/cart/WEB/newNormal`，需登入。AI 的瀏覽器分頁在此頁卡住（腳本注入逾時），以下依據 PM 提供的 3 張截圖整理；截圖含個人購物資料，不存入知識庫。手機版未觀察。

| #   | 觀察                                                                                                                                         |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| O1  | 購物車頁的版頭精簡：只有 logo 與「購物車」字樣，沒有搜尋框與分類導覽                                                                         |
| O2  | 右上有「追蹤清單 N 件」「買過清單 N 件」入口                                                                                                 |
| O3  | 以取貨方式分頁：「宅配/電子票券(13)」「超商取貨(2)」；括號為品項數                                                                           |
| O4  | 「momo訂單」區塊標題列右側有「全部刪除」                                                                                                     |
| O5  | 品項依出貨方式分組（例「快速到貨(6)」），組標題帶勾選框與運費說明「運費$0，滿$490已免運」                                                    |
| O6  | 每個品項一列：勾選框、商品圖、商品編號、出貨標籤（速・最快今日／momo出貨／廠商出貨）、品名、規格（藍色連結）                                 |
| O7  | 品項的促銷狀態：「已符合 滿1件折380元」（綠勾）、「未符合 滿1,511元且滿1件送 mo點111元」＋「差112元享優惠」（橘色）                          |
| O8  | 價格欄標「總計」，顯示該品項金額，有原價時加刪除線原價（例 $1,399 / ~~$1,779~~）                                                             |
| O9  | 數量為「− n ＋」步進器                                                                                                                       |
| O10 | 品項操作：「更改配送方式」「加入追蹤」「移除」；部分品項有「使用折價券」按鈕                                                                 |
| O11 | 組合商品展開「本商品包含：」列出子商品與子選項下拉                                                                                           |
| O12 | 有一筆品項價格變淡、只剩「−」與「移除」，推測為無法購買（缺貨或下架）；截圖被切掉，未確認原因與文案                                          |
| O13 | 勾選不是全部預設：截圖中僅部分品項勾選                                                                                                       |
| O14 | 底部固定列：「結帳總金額 $8,389 已折$7,445」、可展開的「明細」、「結帳(3)」；總金額與結帳件數只計入已勾選品項（推論：件數 = 已勾選品項列數） |
