# REF-002：momo 實站結構觀察（2026-11-20）

> 只記錄**結構與行為**，不複製商品內容或素材。用於 REQ 的範圍判斷與最終的「實作 vs 實站差異」分析。

## 摘要

### 取得方式與觀察

- 單純 HTTP 抓取只拿得到 HTML 殼（標題與導覽），商品內容由前端載入 → 實站內容為**客戶端渲染**為主。
- Headless 瀏覽器被 CDN（Akamai）擋下（Access Denied）；**未嘗試繞過**，改以一般瀏覽器人工檢視。

### URL 形式

| 頁面 | 觀察到的 URL                                                                                          |
| ---- | ----------------------------------------------------------------------------------------------------- |
| 首頁 | `/main/Main.jsp`                                                                                      |
| 搜尋 | `/search/searchShop.jsp?keyword=iphone` → 轉址為 `/search/iphone?cateLevel=0&_isFuzzy=0&searchType=1` |
| 商品 | `/goods/GoodsDetail.jsp?i_code=<id>&Area=search&oid=1_1&kw=iphone` → 轉址為 `/product/<id>`           |

### 共用版頭（各頁一致）

工具列（登入、註冊、會員中心、查訂單、追蹤清單、折價券、購物車(n)）→ Logo ＋ 搜尋框（placeholder 為推薦關鍵字）＋熱門關鍵字列 ＋ 活動圖 → 主分類導覽（首頁／限時搶購／直播／…／各品類）。右側浮動：瀏覽記錄、購物車、TOP。

### 搜尋結果頁

- 麵包屑「Home > 搜尋結果」
- **篩選面板**：品牌、尺寸、功能、容量、畫素等屬性，每個值附件數，例如「Apple (785)」；可展開「選更多」；其他選項為下拉選單。
- **排序列**：綜合推薦（預設）／月銷量／新上市／價格 ↕／評價 ↕；價格區間（最低價～最高價＋確認）；勾選條件如 momo速配、商店免運、超商取貨、折價券、0利率等；棋盤式／條列式切換。
- **分頁**：頂部「頁數 1/27 ＋ 下一頁」，底部頁碼 1–10、＞＞、＞｜。每頁約 30 筆。
- **商品卡**：圖片、促銷標語（例：滿1件折1800）、品名（【品牌】名稱(規格)）、總銷量（例：>5萬）、標籤（折價券／登記／贈險）、價格（「售價已折」）、評價數。

### 商品頁

- 左側：品類側欄（館長推薦、本月主打、系列／容量清單、熱銷 TOP5）。
- 麵包屑：Home \ 手機/相機 \ iPhone \ iPhone 18 Pro \ 256G。
- 圖片區＋活動角標；活動區塊（登記送 mo 點等）。
- **價格區塊**：限時折後價、促銷價、市售價（三種價格並列）；品牌、結帳方式、分期（例：12期0利率，每期 $X）、配送方式與運費門檻（未滿 $490 運費 $75）。
- **購買區**：相關商品（同款不同組合與價格）、規格選擇（顏色等）、數量、限購說明（每人限購1組）、折價券、「直接購買」「放入購物車」「加入追蹤」。
- 下方：組合商品內容、熱門推薦、熱銷排行、瀏覽紀錄。

### 首頁

- 版頭同上 → 主視覺輪播（多張活動橫幅）＋ 右側「今日限定」「今日大牌」。
- 熱搜關鍵字排行（含熱度）、多個商品帶（排行榜 TOP 1–20、主題推薦）。
- **限時搶購**：倒數計時（時:分:秒）、限搶價／原價、剩餘組數（例：最後 285 組）。
- 「大家都在買」：商品卡含總銷量、評價數、標籤。
- 頁尾：防詐騙提醒、關於我們、客服連結、公司資訊。
